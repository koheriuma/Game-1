## Как запустить
1. Склонируй репозиторий
2. Скачай ассеты по ссылке: [Google Drive](https://drive.google.com/drive/folders/1QogpjwCW-d7V49QCvfeslJPNkjTO_WA9?hl=ru)
3. Положи папку `images/` и все `.mp3` в корень проекта
4. Запусти `apr.py`
